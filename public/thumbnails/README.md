# Style Thumbnails

Place style preview thumbnail images here. They are displayed in the style picker strip.

## Expected naming convention

```
{style_name}.jpg
```

Examples:
- `starry_night.jpg`
- `the_scream.jpg`
- `mosaic.jpg`
- `candy.jpg`
- `udnie.jpg`
- `rain_princess.jpg`
- `pointilism.jpg`
- `la_muse.jpg`

## Requirements

- Format: JPEG (for small file size)
- Dimensions: ~200x140px (displayed at 100x70px, 2x for retina)
- Content: A sample of the art style applied to a recognizable photo

If no thumbnail is available, the app shows a fallback SVG placeholder with the style name.
